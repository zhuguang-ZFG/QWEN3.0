# 小智 AI 文档中心

> 来源：https://xiaozhi.dev/docs/
> 抓取日期：2026-07-05

## 项目特色

- 🎙️ **语音唤醒**: 支持"你好小智"等26种唤醒词，<200ms响应
- 🧠 **AI集成**: 支持DeepSeek、GPT、文心一言等多种大模型
- 🏠 **IoT控制**: 集成MQTT、MCP协议，支持智能家居控制
- 🔧 **开源硬件**: 基于ESP32-S3，完整开源方案

## 技术特色

### 硬件平台

- **主控芯片**: ESP32-S3双核240MHz，16MB Flash + 8MB PSRAM
- **音频处理**: INMP441数字麦克风 + MAX98357A数字功放
- **显示输出**: SSD1306 OLED显示屏 + RGB状态灯
- **网络通信**: Wi-Fi 2.4GHz + 4G Cat.1通信(可选)

### 软件架构

- **开发框架**: ESP-IDF v5.4.0+ + Arduino兼容
- **AI引擎**: 乐鑫Wake Word Engine + 云端大模型
- **通信协议**: WebSocket + MQTT + MCP Protocol
- **音频编码**: 16kHz PCM + Opus压缩传输
