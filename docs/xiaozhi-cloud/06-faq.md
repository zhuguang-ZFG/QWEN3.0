# 小智 AI 常见问题解答

> 来源：https://xiaozhi.dev/docs/usage/faq/
> 抓取日期：2026-07-05

## 基础入门

### Q：小智AI机器人复刻操作步骤

1. 购买材料与模块
2. 硬件接线
3. 下载烧录固件
4. 配置设备联网（WiFi 限 2.4G 频段）
5. 登记设备（https://xiaozhi.dev）

### Q：支持哪些大模型？

- Qwen 2.5（实时）
- DeepSeek V3
- DouBao 1.5 Pro
- Qwen Max 2.5

登录管理后台控制面板，在角色配置页面切换。管理后台：https://xiaozhi.dev

### Q：支持接入 GPT 等大模型吗？

暂不支持。需自行实现服务端，可参考小智AI服务端开源基础框架。

### Q：服务端开源吗？

服务端基础框架是开源的，大模型是私有训练和部署。
服务端开源地址：https://github.com/78/xiaozhi

## 功能与使用

### Q：小智AI支持语音控制电机/舵机吗？

默认不支持，需要加舵机/电机驱动模块。ESP32-S3可以利用已接入的 IOT 框架扩展，通过语音控制输出信号到驱动板。

目前已适配 ESP-SparkBot 开发板（坦克）实现小车运动控制。

### Q：小智AI终端支持语音控制其他设备吗？

0.9.7 及以上版本已支持 IOT 物联网框架，支持定义引脚控制开关灯，更多功能可根据需要自行开发。

### Q：如何让小智AI听声辨人记住我是谁？

1. 到后台控制台 → 智能体 → 声纹识别
2. 选择一段语音记录
3. 填写名称和描述
4. 点击 OK 添加说话人
5. 重新唤醒，下次对话会知道你是谁

### Q：可以更换唤醒词吗？

支持，需要配置 IDF 开发环境，在 menuconfig 中修改唤醒词，目前可选约 25 个。

### Q：可以更换声音/音色吗？

支持，到管理后台 → 配置角色中切换角色声音。

## 硬件问题

### Q：喇叭没有声音？

1. 检查喇叭是否接好（红色线为正极）
2. 检查数字功放是否接对
3. 电脑 USB 口供电不足时建议 5V2A 以上充电头

### Q："你好小智"无法唤醒？

1. 确认唤醒词正确（"你好小智"而非"小智你好"）
2. 检查麦克风接线
3. INMP441 麦克风有图标和丝印字母带进声孔的一面朝上
4. 更换备用麦克风测试

### Q：如何重新配网 WiFi？

将开发板重新上电/重启，在连接 WiFi 闪烁蓝灯时，按下 Boot 按钮然后松开，听到提示音重新进入 WiFi 配网模式。

## 开发板支持

### Q：支持哪些开发板？

1. 乐鑫 ESP32-S3-DevKitC-1 开发板
2. 乐鑫 esp-box-3
3. 立创 S3 实战派 lichuang-dev
4. 酷世开发板 kevin-box-1 和 kevin-box-2

其他开发板需修改程序源代码重新编译适配。
